## Procedure for each item

1. Read the morel-java commit (`cd /Users/jhyde/dev/morel.0 && git show <hash>`).
2. Port the implementation to morel-rust.
3. Copy/adapt the `.smli` test changes — these scripts are intentionally shared.
4. Enable any `(* ... *)`-quoted or `set("mode","validate")`-bracketed regions
   that the feature now supports.
5. Run `/usr/local/bin/fullMake --no-clean`. Iterate until it passes.
6. Commit with the morel-java subject as the first line and a
   `Propagates hydromatic/morel#<PR> commit <sha>` trailer.
